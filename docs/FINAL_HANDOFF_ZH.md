# Seed Agent 1.0 — 交付与验收

## 可以使用的产品流程

成员资料 → AI / 关键词找人 → 查看资料匹配与链上证据 → 加入候选 → 核验 → 导出报告。

附加入口：ENSv2 名称解析和注册表路径；World AgentBook 公开注册记录查询。
不同入口加入同一成员会保留来源。列表只在当前页面保存，刷新清空。
报告不导出联系方式字段，不导出 World 的匿名真人标识。
