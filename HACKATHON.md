# ETHOnline 2026

## Project

Seed Club Talent: Verifiable Web3 Builder Network

Seed Club Talent is an existing community member directory. During ETHOnline 2026, it is being extended with wallet-linked profiles, live onchain evidence from The Graph, explainable builder discovery, and ENS identity.

The product question is:

> Who can actually help with this project, and what evidence supports that recommendation?

## Continuity track

This project enters The Graph Continuity track. The pre-hackathon application is preserved in the `pre-ethonline-2026` tag and documented in `PRE_EXISTING_WORK.md`. All competition work is developed on the `ethonline-2026` branch.

## Competition scope

### P0

- Bind an EVM wallet to a member profile.
- Fetch live indexed onchain data through The Graph.
- Build a transparent Onchain Activity Proof from that data.
- Combine profile information and onchain evidence in explainable talent search.

### P1

- Resolve and display ENS identity.
- Complete the English demo flow, documentation, architecture notes, and deployment guide.

### P2

- Add proof-of-human verification only if the core The Graph and ENS flow is stable.

## Non-goals

- Tokens, NFTs, swaps, payments, or a DAO.
- A full visual redesign of the existing product.
- Hidden, mocked, or manually entered onchain activity presented as live evidence.

## Human responsibility

Ray owns the problem definition, product direction, sponsor and scope choices, acceptance criteria, manual product validation, deployment decisions, demo, and final submission. AI tools perform a substantial part of implementation under those decisions. The exact division is documented in `AI_USAGE.md` and `docs/AI_DEVELOPMENT_LOG.md`.

## Delivery checkpoints

1. Preserve and publish the pre-event baseline.
2. Add wallet-linked member profiles.
3. Add live The Graph data and Onchain Activity Proof.
4. Add explainable AI and onchain talent search.
5. Add ENS resolution.
6. Complete end-to-end validation and presentation.
7. Freeze features, record a human-voiced demo, and submit.
